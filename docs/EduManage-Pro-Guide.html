3. إدارة المجتمع المدرسي

الأقسام الأساسية التي تُبنى عليها بقية العمليات داخل التطبيق.

3
🎓

الطلاب

إضافة بيانات الطالب، ربطه بصف وولي أمر، رفع صورة، فتح بطاقة مفصلة، والبحث السريع عنه.

👨‍🏫

المعلمون

بطاقة معلم تشمل المواد، الجدول، الصفوف، الموارد البشرية، الوثائق والشهادات.

👨‍👩‍👧

أولياء الأمور

إدارة حسابات أولياء الأمور وربطهم بالأبناء لمتابعة التقدم والرسوم والتواصل.

🏫

الصفوف

صفحة صف تعرض الطلاب، المعلمين، الجدول، الحضور، الدرجات، والمواد المرتبطة.

1
إنشاء الصفوفحدد أسماء الصفوف والشعب لتصبح أساسًا للجداول والطلاب.
2
إضافة المعلمين والمواداربط كل معلم بتخصصه ومواده حتى تظهر في الجداول والخطط.
3
تسجيل الطلاب وأولياء الأموراربط كل طالب بصفه وولي أمره حتى تعمل البطاقات والتقارير بشكل صحيح.

4. الشؤون الأكاديمية

مجموعة الأدوات التي تدير اليوم الدراسي من التخطيط إلى التقييم.

4
📚

المواد

صفحة لكل مادة تعرض المعلمين، الصفوف، الدرجات، الحصص، وملفات PDF أو صور تعليمية.

📅

الجدول الدراسي

إنشاء حصص واستراحات وإنشاء ذكي للجداول مع مراعاة أوقات الحصص.

✅

الحضور والغياب

تسجيل حضور الطلاب ومتابعة نسب الغياب والتأخر حسب الصف والطالب.

📋

الامتحانات

جدولة الاختبارات وربطها بالصفوف والمواد ومتابعة الحالة والقاعة والمدة.

📘

الواجبات

إضافة واجب حسب المادة والصف، تحديد تاريخ التسليم، الأولوية، وإغلاق الواجب عند الانتهاء.

⚠️

التنبيهات الأكاديمية

متابعة الطلاب الذين يحتاجون دعمًا بسبب الغياب أو انخفاض النتائج.

أفضل ترتيب للعمل الأكاديمي: المواد ← الصفوف ← المعلمون ← الجداول ← الحضور ← الدرجات ← التقارير.

5. كشف الدرجات

تم دمج قسم الدرجات داخل كشف الدرجات ليصبح مركزًا واحدًا للتقييمات والنتائج.

5
🧾

سجل الطالب

كل طالب يظهر كسجل واحد، وعند النقر تظهر جميع نتائج اختباراته حسب المادة والنوع.

⚖️

أوزان المواد

تحديد قيمة كل نوع تقييم، مثل واجب 10%، مذاكرة 20%، نصفي 30%، نهائي 40%.

📤

CSV

تصدير الدرجات كملف CSV للمراجعة أو الأرشفة أو العمل الخارجي.

📄

PDF

طباعة كشف درجات بتصميم موحد يحتوي بيانات الطالب، الملخص، وتفاصيل الاختبارات.

مسار رصد درجة
1
اختيار الطالبافتح كشف الدرجات ثم اضغط إضافة درجة.
2
تحديد المادة ونوع التقييماختر المادة ونوع الاختبار: مذاكرة، واجب، عملي، نصفي، نهائي.
3
إدخال الدرجةاكتب الدرجة والدرجة الكاملة، ثم احفظ. ستظهر النسبة تلقائيًا في سجل الطالب.
4
طباعة الكشفافتح سجل الطالب واضغط طباعة PDF للحصول على كشف جاهز.

📅
